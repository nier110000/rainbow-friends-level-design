# 彩虹朋友（Rainbow Friends）Chapter 2 · 关卡拆解与 UE5 复刻

游戏关卡策划笔试作品。对 Roblox 头部恐怖游戏《彩虹朋友 Rainbow Friends》第二章进行完整的关卡拆解与数据分析，并在 Unreal Engine 5.6 中以第一人称视角 1:1 复刻关卡。

## 文件下载

两个文件体积较大，请前往右侧 **[Releases](../../releases)** 页面下载：

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `package.zip` | ~524 MB | UE5 打包的 Windows 可运行版本。解压后双击 `robloxrainbowlevel2.exe` 直接运行，无需安装任何环境 |
| `拆解文档.zip`（下载文件名为 `teardown-docs.zip`） | ~23 MB | 关卡拆解全套文档（详见下方） |

## 拆解文档内容

- **彩虹朋友_拆解.xlsx** —— 核心数据表：
  - 区域点位表（21 个区域的资源点 / 庇护点 / 交互点 / 出入口 / 开放度等）
  - 资源数据记录（按轮次 × 区域的实测采集数据）
  - 玩法介绍、怪物巡逻、通行时间、动线与节奏结论、优化方案
- **拓扑与数据分析（HTML，浏览器打开）**：
  - 风险收益拓扑图（可拖拽节点的交互式拓扑，含单向通路标注）
  - 动线分析（基于背包上限与回收点规则的玩家动线模拟）
  - 情绪曲线（按轮次的压力 / 节奏曲线）
  - 优化点与改造方案（含第一人称化与平台移植专项）

## 拆解亮点

- **拓扑 1:1 对照**：区域划分与连接关系（含桥→河流 L、滑索→山谷两条单向通路）与原游戏实测一致
- **数据全部实测**：资源刷新点、庇护点、怪物巡逻路径、跑图时间均按秒级实测记录
- **结论可复现**：动线模拟、情绪曲线、风险收益拓扑均由实测数据驱动生成

## 复刻说明

- 引擎：Unreal Engine 5.6（纯蓝图项目）
- 视角：第一人称（遵循题目要求）
- 操作：WASD 移动 + 鼠标视角
